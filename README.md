## How to use
1. Study each section file. Answers + explanations are inline for learning.
2. Take the mock test (`07-mock-test.md`) strictly — write your answers, then submit in the required format to your trainer.
3. Use the section files as a lookup for missed concepts.

## Mock test submission format
After attempting all 50 mock questions without peeking, submit answers as:

```
1-A
2-C
3-B
...
50-D
```

Your trainer will then score: total, %, topic-wise performance, difficulty-wise performance, weakest areas, and issue a personalized weak-area test.
